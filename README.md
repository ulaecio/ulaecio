## Sobre mim

Sou graduado em **Sistemas de Informação pela UNDB**, com experiência em desenvolvimento de software e participação em projetos de governança e segurança da informação.

Sou desenvolvedor dos projetos entregues pela **Ulasoftware Sistemas** apresentados neste perfil. Trabalho com aplicações web, plataformas SaaS, APIs REST e integração com bancos de dados, criando soluções para gestão empresarial, educação e presença digital.

Atuei como **Desenvolvedor Java na MJV Technology & Innovation**, trabalhando com aplicações Java Web, manipulação de dados em **Oracle e SQL** e suporte a sistemas.

Tenho interesse em soluções que conectam tecnologia às necessidades do negócio, combinando desenvolvimento web, integração com bancos de dados e aprendizado contínuo.

- 💻 Minha base de desenvolvimento inclui **Java, Spring, React e JavaScript**.
- 🛡️ Minha formação também abrange **segurança da informação e métodos ágeis**.
- 🎸 Fora do código, gosto de tocar violão, assistir a filmes e trocar ideias.
